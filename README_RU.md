# Кубики для Монополии — Android-проект

Офлайн-приложение с двумя кубиками, определением первого игрока, пятью дизайнами и поддержкой 2–8 игроков.

## Правила и тюрьма
- Три дубля подряд отправляют текущего игрока в тюрьму и завершают его ход.
- Когда ход доходит до игрока в тюрьме, доступны «Оплатить штраф и бросить» и «Пытаться выбросить дубль».
- При оплате штрафа игрок выходит и может бросить кубики в этом ходу.
- При попытке дубля успешный дубль выпускает игрока; неудача оставляет его в тюрьме и передаёт ход. После третьей неудачной попытки игрок автоматически выходит, штраф считается оплаченным, и ход заканчивается.
- На вкладке «Игроки» есть кнопка ручного отправления текущего игрока в тюрьму (например, по карточке или клетке поля).

Важно: приложение не отслеживает перемещение по полю, баланс, карточки и фактическую оплату денег. Сумма штрафа не списывается автоматически — игроки учитывают деньги сами.

## Сборка APK
Требуется Android Studio с Android SDK и Gradle. Откройте папку проекта, дождитесь синхронизации, затем выберите Build → Build Bundle(s) / APK(s) → Build APK(s). APK обычно находится в `app/build/outputs/apk/debug/app-debug.apk`.
